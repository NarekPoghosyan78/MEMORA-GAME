# 🃏 Memora — Memory Card Game

**Memora** is an interactive memory card game designed to challenge your concentration, improve your memory, and provide an enjoyable gaming experience. It combines engaging gameplay with a stylish dark fantasy-inspired interface.

## ✨ Features

- 🃏 **Interactive Gameplay** — Flip cards and find matching pairs.
- 🎨 **Elegant UI** — Dark, fantasy-inspired design with stylish details.
- ⚙️ **Customizable Settings** — Adjust game preferences and difficulty.
- 🔊 **Sound Effects** — Audio feedback for different game events.
- ⏱️ **Game Timer** — Track your time while playing.
- 🏆 **Win and Lose States** — Get feedback based on your game progress.
- 🔄 **Restart Functionality** — Start a new round without reloading the page.
- 📱 **Responsive Design** — Enjoy the game across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3 / SCSS
- Vanilla JavaScript

## 🎮 How to Play

1. Start a new game.
2. Click on a card to reveal its symbol.
3. Select another card to find a matching pair.
4. Remember the positions of previously revealed cards.
5. Match all pairs to complete the game.
6. Try to finish with the fewest moves and in the shortest time possible.

## 🚀 Getting Started

### Prerequisites

You need a modern web browser to run the game.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/NarekPoghosyan78/MEMORA-GAME
   ```

2. Navigate to the project directory:

   ```bash
   cd MEMORA-GAME
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
